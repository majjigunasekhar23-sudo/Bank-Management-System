# Bank Management System

## Project Description
The Bank Management System is a simple C++ application developed using Object-Oriented Programming and file handling. It helps users perform basic banking operations such as account creation, depositing money, withdrawing money, and checking account balances.

## Features
- Create a bank account.
- Deposit money.
- Withdraw money.
- Check account balance.
- Store account details using file handling.

## Technologies Used
- **Programming Language:** C++
- **Concepts:** Classes, Objects, Functions, Conditional Statements, Switch Case and File Handling.

## Files Included
- `BankManagement.cpp` – Main C++ source code.
- `bank.txt` – Stores account information (created automatically when the account is saved).

## How to Run
1. Open the source code in VS Code or any C++ compiler.
2. Compile and run the program.
3. Select an option from the menu.
4. Perform the required banking operations.

## Expected Outcome
A simple application that performs basic banking operations and stores account details using file handling.

## Conclusion
This project demonstrates the practical implementation of C++ programming and Object-Oriented Programming concepts in a basic banking application.
